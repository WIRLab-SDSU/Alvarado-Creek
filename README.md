# Alvarado Creek

This repository contains preliminary data and analysis files for the Alvarado Creek project.

The data included here are provisional and may be incomplete, unverified, or subject to revision. Values, figures, scripts, and outputs should not be treated as final results. Any interpretations based on these files should be considered preliminary until the data have been reviewed, validated, and documented more fully.

Additional documentation, processing details, and finalized analysis products may be added as the project develops.
